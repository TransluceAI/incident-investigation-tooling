EVIDENCE SHAPE: ARCHIVED OR REDIRECTED REQUEST
The item is a request URL observed by a web archive, link shortener, or redirect service, with any stored response. The request URL and its decoded views are often the main evidence, and a missing body does not prevent judging them. The archive or shortener that stored the observation is collection machinery, not the actor; its replay status describes the archive, and the stored response describes the target only when the archive captured the target's own response. An empty or error body with an ordinary URL is insufficient_evidence.
