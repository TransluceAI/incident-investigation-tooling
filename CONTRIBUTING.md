# Contributing

Contributions are welcome. To add a tool:

1. Fork the repository and create a branch.
2. Add your tool in a new subdirectory, e.g. `my-tool/`.
3. Include a `README.md` in that subdirectory that explains what the tool does, how to install it, and how to run it.
4. Add an entry to the Tool Index in the root `README.md` that links to your subdirectory and describes your tool in one sentence, e.g. `- [my-tool](my-tool/): Detects coordinated activity across agent accounts.`
5. Open a pull request with a short description of the tool.

## Requirements

- All of your files live inside your tool's subdirectory.
- Your subdirectory has its own `README.md`.
- Do not commit credentials, API keys, or private data.
- This repo is for code. Host large datasets elsewhere and link to them from your tool's README.
